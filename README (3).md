# LegacyConnect

面向 Minecraft Bedrock `1.16.100.4`（协议 `419`）的透明 RakNet 10 中转器。

## 功能

- 保存并检测多个 Bedrock 服务器
- 以原始 UDP 数据报透明转发 RakNet，不拆除原会话
- 域名解析到多个 IP 时自动选择 RakNet 延迟最低的地址
- 可选择 `1.16.100.4 / 419`、`1.12.1 / 361` 或自定义版本与协议
- 不处理微软账号密码，不改写游戏登录包
- 本地网页控制面板
- 显示活动连接和累计流量

## 使用

双击 `LegacyConnect.exe`，浏览器会打开控制面板。

1. 添加一个仍兼容协议 `419` 的服务器。
2. 点击“使用”选中它。
3. 点击“启动”。
4. 在 Minecraft 中添加服务器 `127.0.0.1:19132` 并加入。

也可以使用命令行版本直接启动：

```powershell
.\LegacyConnect-cli.exe --target play.example.com:19132
```

## 限制

- 透明中转不会转换游戏协议。`1.16.100.4` 只能进入仍支持协议 `419` 的服务器。
- 本机中转本身不会降低公网延迟；若部署在延迟更低的远端节点，才有机会改善路由。
- 程序使用旧版 RakNet 协议 `10`，这是 Minecraft `1.16.100.4` 所需的版本。
- 版本配置只改变本地服务器列表中的 Pong 信息，不会改变远端真实延迟。
